TL;DR for Claude Code users: your tool's behavior changes almost every release, none of it is in the    
 changelog, and we can now prove it.                                                                                                                               
                                                                                                                                                                   
 We built a proxy that captures the system prompt Claude Code actually sends to the API — byte-exact, API-verified, isolated from local                            
 settings — for every CLI version × model. ~470 verified captures later, here's what the wire says:                                                                
                                                                                                                                                                   
 - The prompt changed in ~80% of version intervals we sampled. Releases ship near-daily. Over one 28-version window, we measured 15 prompt                         
   changes and 15 tool-definition changes: 0 of 15 prompt changes and 13 of 15 tool changes appear in the changelog. When Claude "feels                            
   different today," you're not imagining it — and there's no public record of why.                                                                                
 - There is no single "Claude Code prompt." In the same build (2.1.228), Sonnet 5 runs a 27KB prompt that tells it to proactively spawn                            
   subagents, while Opus 5 runs a 9KB prompt that says "Do not call the AgentTool unless the user requested it." Same tools, opposite                              
   instructions. Per-model patches ship at launch: Opus 5's GA build added "finish the whole task, don't relitigate" doctrine and removed a                        
   stop-and-check clause on deleting files that its sibling models still have.                                                                                     
 - Even the prompt's facts can be stale: for two releases the prompt told the model Opus 4.7 supported fast mode after that was removed. The                       
   model was confidently wrong about its own harness.                                                                                                              
 - Tool descriptions are the bigger instruction channel — 7.6× the system prompt by size, changing even faster, rolled out per-model in waves.                     
   Some rules there are revealing: "Never fabricate or predict a pending agent's results" wasn't written for fun.                                                  
 - Also in there: your CLAUDE.md composes into the system prompt, feature flags can change your prompt without a version change, and                               
   prompt-cache economics (not semantics) dictate the prompt's structure.                                                                                          
                                                                                                                                                                   
  What this means for you: treat "Claude Code" as a moving target with three parts — model, prompt-state, tool-state — each on its own silent                      
 release cycle. If your workflow broke overnight, pin your CLI version and diff before blaming yourself or the model.                                              
                                                                                                                                                                   
 What we want from Anthropic: you already publish system-prompt release notes for claude.ai. Do it for Claude Code. Until then, the wire is the                    
  changelog.                                                                                                                                                       
                                                                                                                                                                   
 (Method: ANTHROPIC_BASE_URL → local proxy, request captured before forwarding, run only counted if the API confirmed serving the requested                        
 model. No TLS interception, no model self-reporting — a model's description of its own prompt is not evidence.)
