                                                                                                                                                               
 Every time you run Claude Code, the CLI secretly sends the model two things along with your message:                                                              
                                                                                                                                                                   
 1. The system prompt — a text document of instructions ("you are an agent, don't add comments, ask before deleting…")                                             
 2. Tool definitions — descriptions of every tool it can use (Bash, Edit, Read…), which also contain instructions                                                  
                                                                                                                                                                   
 We built a proxy that records exactly what gets sent, for 255 versions of the CLI. When you line those captures up in order, you can watch Anthropic change their 
 mind in real time. Here's what the timeline shows coming next.                                                                                                    
                                                                                                                                                                   
 ────────────────────────────────────────────────────────────────────────────────

 2. The system prompt itself is being phased out as the control mechanism                                                                                          
                                                                                                                                                                   
 The system prompt used to be the way to control behavior.  Plain version: instructions are temporary scaffolding. They write a rule when the model misbehaves, keep it until the next model is trained not to need it, then  
 delete it. We watched ~82% of all rules ever written get deleted this way. And the deleting is speeding up — the cleanup cycles went from ~4.5 months apart to ~6 
 weeks apart.                                                                                                                                                      
                                                                                                                                                                   
 3. The replacement: rules injected mid-conversation                                                                                                               
                                                                                                                                                                   
 This is the subtle one. At 2.1.207 (July 2026), one paragraph in the prompt changed:                                                                              
                                                                                                                                                                   
 │ Before: system reminders are "tags injected by the harness"                                                                                                     
 │ After: "The system may send updates, reminders, or modifications to rules via mid-conversation system turns."                                                   
                                                                                                                                                                   
 Why that matters: you don't rewrite the rulebook to say "rules can change mid-game" unless you're about to start changing rules mid-game. Today, changing         
 Claude's behavior requires shipping a new CLI version. This paragraph paves the way for changing behavior live, during your session, without any release at all.  
 If that lands, version-to-version prompt tracking (this whole project!) stops seeing the real control channel — which is why the next thing to capture is the     
 mid-session messages, not just the startup prompt.                                                                                                                
                                                                                                                                                                   
 4. Two more things they've already tried or built, sitting in the data                                                                                            
                                                                                                                                                                   
 - Tool loading on demand. For exactly one version — 2.1.69, alive for 26 hours in March 2026 — the CLI replaced all 18 tools with a single ToolSearch tool        
   ("search for tools, then load them"). Then it was rolled back. Companies don't build that unless the tool list is about to get too big to send every time.      
   Expect it back.                                                                                                                                                 
 - A gated model tier, described in the prompt itself. Fable-5's prompt (added at 2.1.172) says: "Claude Fable 5 and Claude Mythos 5 share the same underlying     
   model… Mythos 5 is available without those [safety] measures to only approved organizations." That's an unreleased-to-you product tier, stated as fact in text  
   we captured off the wire.

 The one-sentence version                                                                                                                                          
                                                                                                                                                                   
 They write rules when models fail, delete the rules once models are trained, and they're now building the pipes to do that correction live during your session    
 while agents increasingly coordinate with each other instead of asking you — and every step of that is visible as specific tools and paragraphs appearing and     
 disappearing at specific version numbers.
